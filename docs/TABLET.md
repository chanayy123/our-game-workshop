# 平板提修改想法

1. 打开 [游戏合集](https://chanayy123.github.io/our-game-workshop/games/)。六款游戏都提供触屏操作；若按钮未显示，点左下角“触屏按钮：关”打开。真实平板性能需要设备验证。
2. 有想法时回到合集，在“我想改一下”选游戏，用平板输入法麦克风输入文字，点“复制修改想法”。不调用我们自己的语音 API。
3. 打开 [Codex 云端](https://chatgpt.com/codex/cloud)，选择工作位置“云端”，选择“我们的游戏工坊”环境，粘贴并发送。平板需登录创建环境的同一账号，并有 Codex 云端权限和可用额度；普通聊天并不自动修改仓库。
4. Codex 完成后可继续在同一个任务里提出调整。查看检查结果，创建修改请求（PR），在 GitHub 合并到 main 后，工坊自动发布。
5. 等待 [Build and publish workshop](https://github.com/chanayy123/our-game-workshop/actions/workflows/pages.yml) 成功，回游戏刷新。失败不会部署失败的构建，旧网站继续可用。

第一次可试：“白鲨海峡的船最高速度提高一点，其他玩法保持原样。先告诉我改了什么，准备修改请求。”

孩子不需要安装 Node.js、Git、Codex 桌面端或付费 API。提想法、云端改代码、合并、自动发布是四个不同步骤；目前保留合并步骤，没有设置无人审批自动改写公开游戏。

## 平板操作

按钮按触摸能力显示，不依赖手机宽度；横屏、竖屏或“请求桌面网站”均可使用。按住方向键移动，松手停止输入；允许一只手移动、另一只手快跑或拖动画面。切换应用、暂停或取消触摸会清除按住状态。

| 游戏 | 触屏操作 |
| --- | --- |
| 鹈鹕骑行 | 屏幕下方左右换道、跳跃、加速；按住刹车。全屏也显示按钮。 |
| 逃离恐龙岛 | 左侧方向键，中央快跑开关；右侧吼叫、攻击、进食和拍照；拖动画面环顾。 |
| 溪流手记 | 左侧方向键；右侧选石头、泥土、挖掘或移除，再点/按住附近地面；放大、缩小按钮调整视野。 |
| 不许动，盆栽！ | 左侧方向键和按住快跑；右侧变身、旋转、声响、烟幕。警察角色会显示对应的观察和攻击动作。 |
| 白鲨海峡 | 左侧驾驶/甲板方向键、停船；点交互按钮离开驾驶位或进出潜笼。潜笼中方向键变为下潜/上浮，右侧攻击、换武器、装填。上岸后攻击变为砍树，按住维修修船。拖动画面环顾。 |
| 伏沙猎手 | 左侧方向键和按住快跑；右侧按住咬击、潜沙、潜水、交互；拖动画面环顾。 |

每次发布自动运行平板横竖屏触摸检查；它验证输入、按钮遮挡和资源错误，并不等同于真实设备、所有关卡或所有胜负分支验收。
