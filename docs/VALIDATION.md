## 平板操作修复 · 2026-10-11

确认问题：溪流和躲猫猫的方向键依赖手机窄屏宽度，平板横屏不显示；鳄鱼/恐龙的部分检测仅依赖 coarse pointer；白鲨没有完整触屏移动和动作入口；鹈鹕原控制栏在画面下方，滚动与全屏不便操作。

增加共享的触摸能力检测与“触屏按钮”手动开关，并保留各款游戏自己的动作与规则。按钮至少约 44px，横竖屏检查按钮中心是否被遮挡。方向/快跑按 pointer ID 管理，触摸与键盘状态分开；松手、取消、暂停和切换应用会释放输入。白鲨新增驾驶、甲板、潜笼、武器、装填、维修按钮；触屏拖动环顾与射击分开。鹈鹕全屏保留操作，溪流补上缩放，躲猫猫两个角色都可用触屏。

同步并保留远程刚合入的翼龙功能后，六套规则测试共 178 项通过；六款类型检查和生产构建通过。根桌面浏览器回归 27 项通过；平板触摸检查 83 项通过，运行和资源错误 0。报告写入 qa/tablet-local.json，12 张横竖屏截图在 qa/tablet-<slug>-<orientation>.png。自动发布流程增加 npm run test:tablet；PR 和 main 都执行此检查，失败不部署。
