# Shark Sea Survival · 白鲨海峡

Play: https://chanayy123.github.io/our-game-workshop/shark-sea-survival/

Desktop keyboard and mouse. WASD sail / walk; E interact; W/S lower / raise the cage; 1/2 select weapon; left click/F attack; R reload or repair; B dock.

Compiled Three.js game. Original procedural art and sound; dependencies and attribution: ASSETS.md and licenses/.
