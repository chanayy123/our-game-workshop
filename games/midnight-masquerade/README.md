# 不许动，盆栽！

**Midnight Masquerade** 是一款可以在浏览器直接游玩的 3D 伪装躲猫猫小游戏。每局可以选择当伪装者，变成物体躲过搜查；也可以选择当警察，寻找并抓住会逃跑的 AI 伪装者。

## 启动

需要安装 **Node.js 22.12 或更高版本**，推荐使用当前 LTS 版本。首次安装依赖需要联网，安装完成后游戏不需要远程素材。

Windows 下双击 `start.cmd`：首次自动安装依赖，然后启动服务并打开浏览器。

也可以在本目录打开终端运行：

```powershell
npm ci
npm run dev
```

打开 **http://127.0.0.1:5184**，点击开始按钮游玩。保持启动服务的窗口开启；关闭窗口或按 `Ctrl+C` 可停止服务。

发布构建及本地预览：

```powershell
npm run build
npm run preview
```

预览地址为 **http://127.0.0.1:4184**，构建文件位于 `dist/`。不要直接双击 `index.html` 或 `dist/index.html`，请通过上述服务访问。若端口已被其他程序占用，请先关闭占用端口的服务。

## 怎么玩

标题页选择「当伪装者」或「当警察」，再点击开始。暂停菜单、结算页都能返回标题更换角色；「再玩一局」沿用本局身份。

伪装者一局分为 **30 秒准备**和 **120 秒搜查**。准备时熟悉环境，靠近一个物件并复制外形，再找一个合理的位置静止下来。可以提前让警察入场。

| 操作 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| `E` | 复制附近物件 |
| 鼠标点击附近物件 | 精确选择并复制 |
| `Q` | 旋转当前朝向 |
| `Shift` + 移动 | 快跑，消耗体力 |
| `空格` | 向鼠标指向的位置制造声响，引开警察 |
| `F` | 使用烟幕，每局 2 次 |
| `Enter` | 准备阶段提前开始搜查 |
| `Esc` | 暂停 / 继续 |

伪装后仍然可以移动、旋转、换一种外形，或制造声响。但警察能看到的移动会显著增加危险。界面会显示当前阶段、倒计时、伪装外形、环境融入程度、怀疑度、是否暴露，以及两名警察各自的生命。

搜查剩余 **85、45、15 秒** 时，变身魔法会忍不住打一个响嗝。附近警察可能循声靠近：提前观察路线、把声响诱饵扔到其他位置，或趁视线被挡住时换个藏身点。响嗝并不会直接把你的位置通知给全地图的警察。

搜查第 35、75、105 秒会出现「魔法打嗝」，界面提前 8 秒提醒。附近警察会调查发声位置，适时转移会更安全。

坚持到搜查结束即获胜；两名警察都因误判耗尽生命也会获胜。被击中识破后进入追捕，尚有机会使用烟幕和遮挡甩开警察、重新藏好；让警察持续贴近则会被抓。结果界面可以重新开始下一局。

选择警察后，你控制林警官，周警官自动巡查。**5 秒准备**后开始 **120 秒搜查**，也可按 Enter 提前开始。AI 对手会选择藏点、变成物体，被识破后会逃跑、绕墙、放两次烟幕并尝试重新藏好。地图上的「你」标记跟随你控制的警官，界面不会标出隐藏对手的身份或位置。

| 警察操作 | 功能 |
| --- | --- |
| `W A S D` / 方向键；`Shift` | 移动；快跑 |
| `E` / 点击附近物体 | 观察摆放与移动线索，不扣生命 |
| `空格` | 攻击选中或身边的物体；误击普通物体扣自己 1 格生命 |
| `Q` | 朝鼠标指向查看 |
| `F` | 吹哨，使已识破、近处且在视线内的对手短暂停步；冷却 15 秒 |
| `Enter` / `Esc` | 提前开始搜查 / 暂停 |

攻击需要走近且不能隔墙。识破后持续贴近即可抓捕，任一警官抓住对手都算搜查成功。时间耗尽或你自己的 10 格生命耗尽则失败。

## 躲藏与搜查

地图有咖啡露台、花园、货运角和中央广场，提供 7 种可复制外形。货箱、椅子、花盆群既能提供藏身思路，也会影响通行。矮墙、绿篱和摊位分割视线，巡警沿不同路线搜查各个区域。

警察不是抽签攻击：它们会巡逻、停下来观察，再靠近可疑物件检查。异常区域、孤零零的摆放、堵住通道、可疑朝向以及被目击的移动都会影响判断；声响会吸引调查。攻击普通物件会扣除执行攻击的那位警察 **1 格生命**，并留下检查记忆；另一位不会连带扣血。

警察不会直接读取躲在墙后的玩家位置来追踪。追捕依赖可见目标和最后目击位置，失去视线后会调查并尝试重新发现目标。两名警察的生命、路线、怀疑和已检查物件彼此独立。

花盆靠近花盆群通常比摆在通道中央自然；桌椅应留出合理间距和朝向。更小的外形便于穿行，更大的物件也能成为荒诞的藏身选择。留意警察的观察方向和头顶提示，在它们转身时调整位置，比一直快跑更容易蒙混过关。

## 实现与素材

- TypeScript + Three.js + Vite；纯前端运行，无账号、后端或在线服务。
- 场景、角色、七类道具、灯光、粒子和界面由项目代码生成，无外部模型、贴图、字体或素材下载。
- 环境音乐与音效通过 Web Audio 程序合成；需要点击开始后才能发声，可以静音。暂停时声音也会淡出。
- 项目自制美术和声音没有第三方素材授权要求；Three.js、Vite 等软件依赖按各自许可证使用，完整版本由 `package-lock.json` 固定。
- 面向桌面浏览器的键盘鼠标操作；推荐使用支持 WebGL 的近期 Chrome 或 Edge。触屏操作未作为本版目标。

`DESIGN.md` 记录设计约定，`src/` 为实现，`tests/` 与 `tools/` 提供规则和浏览器验证入口。实际验收结果以本次交付说明和 `qa/` 中保留的验证记录为准。

## 验证命令

先启动开发服务，然后在另一终端运行：

```powershell
npm test
npm run test:browser
npm run test:police
npm run test:playthrough
```

`test:browser` 验证伪装者回归；`test:police` 验证角色选择、警察操作、AI 逃跑、抓捕与失败。两者使用本机 Chrome，混合真实按键/点击和明确标记的 QA 场景、加速时间。`test:playthrough` 是伪装者的完整键鼠回合，读取状态但不传送、不改生命、不加速时钟。这些是可重复的浏览器操作脚本，不是人工玩家调研。详见 `VALIDATION.md`。
