# Pelican Pedal Club — The lighthouse run

**A little ride. A little joy.** 控制骑着珊瑚红自行车的鹈鹕 Percy，在 900 米海岸公路上收集小鱼、跳取天空珍珠、管理连击与加速，带着午餐抵达灯塔。清爽的海岸配色、程序化角色和小岛保留下来；固定路线可以反复练习，金牌需要主动选择风险。

## 本地运行

```sh
npm ci
npm run dev
```

访问 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。Windows 可以双击上一级的 `start.cmd`；PowerShell 如限制脚本执行，可使用 `npm.cmd` 代替 `npm`。终端中按 `Ctrl+C` 停止服务。

需要 Node.js 20.19+ 或 22.12+，以及支持 WebGL 2 的现代浏览器。当前验证环境使用 Node.js 22.17.0。首次安装依赖需要联网；运行时模型、字体、图标和声音均在本地生成或打包，无需账号、API key 或 CDN。

```sh
npm test         # 21 项游戏模型自动测试
npm run build    # TypeScript 类型检查与生产构建
npm run preview  # http://127.0.0.1:4173/ 预览生产构建
```

构建输出在 `dist/`，请通过 HTTP 静态服务器访问，不要直接双击 `index.html`。端口被占用时，停止原服务，或使用 `npm run dev -- --port 5174`；服务不会自动换到另一个端口。

## 游戏目标与节奏

点击 **Let’s ride**，倒计时后开始。Percy 自动前进，玩家选择三条车道、跳跃时机、何时冲刺以及何时刹车。带着至少一颗心完成 900 米即可获胜；三颗心全部失去则本次骑行结束。

| 路段 | 距离 | 基础速度 |
| --- | --- | --- |
| Palm promenade | 0–300 m | 9 m/s |
| Driftwood bay | 300–600 m | 10.2 m/s |
| Lighthouse climb | 600–900 m | 11.4 m/s |

不刹车、不加速且不受伤时约 89 秒完成，不含开始倒计时。路线按教学、换道、跳跃支路、双障碍和恢复段编排；后段速度更高、节奏更密。金色小鱼指向安全路线，漂流木上方的青绿色珍珠提供额外风险收益，每组障碍均留有安全车道。

每次重玩使用同一路线，便于熟悉节奏、提高成绩。结算展示得分、用时、珍珠、小鱼、最佳连击和成功跳过的障碍数，并列出还缺少的金牌条件。

## 操作

| 操作 | 作用 |
| --- | --- |
| `← / →` 或 `A / D` | 换道；按住可继续向该方向换道 |
| `Space`、`↑` 或 `W` | 跳过漂流木、取得空中珍珠 |
| 按住 `S` / `↓` 或 **Brake** | 降至基础速度的 65%；若正在冲刺，立即取消剩余冲刺 |
| `Shift` | 能量充满时启动四秒加速 |
| `P` / `Esc` 或暂停按钮 | 暂停、继续；暂停面板也可重新开始 |
| `B` 或铃铛按钮 | 鸣铃并挥翼问好 |
| `?` 或 **How to play** | 打开说明；骑行中打开会暂停 |
| 日光 / 日落 / 星夜按钮 | 切换光照、海水与界面色彩 |
| 声音按钮 / `M` | 首次主动开始后播放声景；可提前静音，也可随时切换 |
| 相机按钮 | 保存当前 3D 场景为 PNG 照片 |
| 全屏按钮 | 进入、退出全屏 |

触屏可以点击页面按钮，或在道路画面上向左 / 右滑动换道、向上滑动跳跃、向下滑动加速；按住 Brake 减速。用键盘聚焦 Brake 后，按住 Space / Enter 也可以刹车。镜头自动跟随，不需要同时操作摄像机。

跳跃持续 0.9 秒，落地恢复约 0.06 秒；临近落地的一次提前按键可以缓冲到下一跳，持续按键不会自动无限连跳。路锥必须绕开。

切换标签页或窗口失去焦点时自动暂停，返回后主动继续。关闭帮助面板也不会自动恢复。暂停冻结里程、连击、跳跃、无敌和加速计时；环境仍可轻微运动。系统“减少动态效果”偏好会减少粒子、摇晃、速度线与环境动画，保留必要的游戏动作。

## 奖励、连击和风险

所有下表中的奖励分数先乘当前连击倍率；冲刺期间再乘 2。路程分与终点奖励不参与该倍率。

| 行为 | 基础分 | 连击与能量 |
| --- | --- | --- |
| 收集小鱼 | 100 | 连击 +1；能量 +12.5% |
| 跳取天空珍珠 | 350 | 连击 +1；能量 +25% |
| 成功跳过漂流木 | 200 | 连击 +1 |
| 贴近障碍安全通过 | 75 | 不延长连击、不增加能量 |

- **六秒连击窗口**：每条鱼、每颗珍珠、每次成功跳过漂流木都会续满六秒。达到第 5 / 10 / 15 次有效动作后进入 ×2 / ×3 / ×4，达到门槛的那次动作即使用新倍率。遗漏一个收集物不会立刻清空，但六秒没有续接或遭到实际伤害都会清空连击。最佳连击仍保留在本局统计中。
- **加速**：八条鱼即可充满，珍珠会更快补充能量。启动时消耗整条能量，速度提升至基础速度的 1.5 倍，持续四秒；可以继续收集，为下次冲刺充能。冲刺期间仍需避障。刹车会放弃剩余冲刺时间，不返还能量。
- **珍珠支路**：珍珠与漂流木处在同一位置，必须在穿越时确实腾空；成功越过时可以同时获得跳跃奖励和珍珠奖励，也会分别延长连击。
- **贝壳护盾**：吸收一次碰撞，保留生命与连击；不能叠加。
- **碰撞**：无护盾时扣一颗心、清空连击，并短暂减速，约 0.7 秒恢复。碰撞后有 1.8 秒无敌，避免连续扣血。
- **路程分**：每完成一米获得 1 分。
- **终点奖励**：`1000 + 剩余生命 × 250 + floor(max(0, 100 - 本局用时秒数) × 35)`。倒计时和暂停不计入本局用时。

通关时发放奖牌：

| 奖牌 | 条件 |
| --- | --- |
| 金牌 / Gold postcard | 至少 5 颗珍珠、18,000 分、2 颗剩余生命，三项同时满足 |
| 银牌 | 未达到金牌，但总分至少 11,000 |
| 铜牌 | 其余成功抵达灯塔的骑行 |

奖牌分数包含终点奖励。失败不发放奖牌。个人最高分在通关或失败时保存；最快用时只记录成功通关。记录保存在当前浏览器的版本化本地存储中，存储不可用时仍可正常游玩。

## 状态与实现

模型状态为 `ready → running → paused / won / lost`；暂停可以返回 `running`，结算后重开会重置整局状态。开始倒计时由界面控制，在模型的 `running` 状态下暂缓推进。重新开始会恢复原始路线、生命、分数、连击、护盾、加速、跳跃和统计，不清除个人记录。

`game.ts` 独立于浏览器，以固定子步推进；碰撞使用经过物品位置时的实际横向位置与跳跃高度，而不是玩家选择的目标车道。场景、界面和声音由同一份状态及事件驱动。较大的帧时间受限，避免后台恢复后跨过未见障碍。

```text
src/
  game.ts       固定路线、碰撞、跳跃、刹车、六秒连击、计分与奖牌
  main.ts       倒计时、键盘 / 触屏、HUD、暂停 / 结算、个人记录
  scene.ts      Three.js 角色、跟随镜头、道路、地标、粒子与资源回收
  sea.ts        原创风格化水面 Shader
  sound.ts      海浪 / 风 / 胎噪、生成式音乐和游戏事件音效
  style.css     响应式界面、可滚动结算与三种光照主题
scripts/
  game.test.mjs 21 项游戏模型自动测试
public/
  favicon.svg   项目标识
DESIGN-NOTES.md 参考分析、体验差距与设计取舍
VALIDATION.md   浏览器、视觉、性能及稳定性验证记录
```

场景采用程序化几何、PBR 材质、环境反射、实时阴影、按材质合批、实例化道路与粒子，以及可回收的物品网格。水面使用滚动法线、浅深水色、Fresnel、细碎反光、岸边泡沫和远处雾色融合；暮色与星夜有漂浮闪烁的暖色萤火虫。转向倾斜与回正使用平滑过渡，围巾随速度连续摆动。128 个事件粒子和 72 个萤火点采用固定预算，持续低帧率时可自动降低像素比及阴影分辨率。

声景由独立海浪、浪花、风声、胎噪、轻微飞轮声及原创旋律构成。冲刺增强风声与音乐层次；刹车立即结束冲刺声，腾空暂时消除胎噪；海浪保持自己的呼吸节奏。页面加载不自动出声，第一次主动开始会启用声音，开始前选择的静音会保留。

## 验证与只读诊断

本次游戏模型测试为 **21 / 21 通过**，覆盖状态边界、连续位置碰撞、跳跃与输入缓冲、珍珠高度、连击截止时间、刹车取消冲刺、碰撞恢复、奖牌、固定路线安全路径和跳跃路径、低帧率一致性及反复重开。模型路径测试验证了安全路线可通关、主动选择珍珠路线可获得金牌；这不等于人类玩家实测难度结论。

声音模块另做了 **15 分钟模拟 WebAudio 调度检查**，覆盖未授权静音、暂停、后台静音、恢复不积压、声音 / 节点数量上限及清理；模拟结果不代表实际设备听感。浏览器实际游玩、截图和性能证据见 [VALIDATION.md](./VALIDATION.md)。

访问 [http://127.0.0.1:5173/?qa=1](http://127.0.0.1:5173/?qa=1)，在控制台调用：

```js
window.__pelicanQA.snapshot()
```

它返回状态副本、倒计时、个人记录和渲染诊断，包括最近最多 180 帧的平均 / P95 帧时间、draw calls、三角形、几何 / 纹理数量、活动 / 池化物品、粒子预算、画质和像素比。接口不提供换道、加分、传送或改写状态的能力；正式页面默认不暴露此诊断对象。帧时间是当前浏览器下的观测窗口，不是跨设备性能保证。

参考研究与实现取舍见 [DESIGN-NOTES.md](./DESIGN-NOTES.md)。依赖版本锁定在 `package-lock.json`。DM Sans / Fraunces 字体使用 SIL OFL，Lucide 图标使用 ISC；依赖包内保留许可证。
