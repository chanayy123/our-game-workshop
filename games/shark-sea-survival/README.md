# Shark Sea Survival · 白鲨海峡

驾驶 10 米级小型捕捞船「晨潮号」，横渡 1.8 公里的白鲨海峡，抵达北岬灯塔。途中可停船、离开舵台，步行到左后方的金属潜水笼，下降至 38 米深处观察和防御大白鲨，再上浮继续航程。船体受损后可停靠沿途四座小岛，拿斧头砍树，收集木材修船。

## 启动

建议使用 Node.js 22.17+（本机已验证版本）；规则测试使用 Node.js 22 的 TypeScript 支持。在本目录执行：

```powershell
npm.cmd install
npm.cmd run dev
```

浏览器打开 <http://127.0.0.1:5185/>。Windows 也可以双击 `start.cmd`。开发服务器仅监听本机。

构建和检查：

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

生产预览地址：<http://127.0.0.1:4185/>。项目不需要账号或远程游戏服务，字体、模型和音效均随构建自包含；第一次安装依赖需要联网。

## 操作

| 状态 | 操作 |
| --- | --- |
| 驾驶 | W 增加油门，S 减油门 / 倒车；A / D 左右转向。松开 W 后保留油门。 |
| 停船 | 空格停船；航行中按 E 会先减速抛锚，停稳后再按 E 离开驾驶位。 |
| 观察 | 按住右键拖动或使用方向键环顾；驾驶时左键拖动也可环顾。V 在追船和舵台视角间切换。 |
| 甲板 | WASD 移动；靠近左后方潜笼按 E 进入；靠近前方舵台按 E 继续驾驶。按住 R 消耗木材维修船和笼架。 |
| 靠岸 | B 切换至小岛导航；在挂旗码头 19 米内停船，再按 B 上岸。回到码头按 B 登船。 |
| 伐木 | 码头 E 拿斧头，WASD 走近海松，F / 左键砍三次。树倒下后 E 收集 4 份木材。 |
| 修理 | 码头附近或甲板按住 R，每份木材修复 25 船体和 18 笼架。无木材不能维修。 |
| 潜笼 | W / Shift 下潜，S / 空格上浮，松开保持深度。上浮到 0 米按 E 返回甲板。无氧气机制。 |
| 战斗 | 1 鱼枪，2 潜水刀；左键 / F 攻击；R 装填。鱼枪每匣 5 发，可反复装填；刀需靠近笼边。 |
| 暂停 | Esc / P 暂停，H / 右上角 ? 打开操作指南；切走窗口时自动暂停。 |
| 声音 | 右上角切换声音。声音在首次点击启航后启动，建议耳机。 |

笼中左上角会提示附近鲨鱼的大致方位。巡游与观察不一定是攻击，转向蓄势、加速直冲时应瞄准防御或上浮。笼架归零后，钢条弯折，白鲨扑咬并把玩家拖入深海；约 6 秒后进入失败界面，可以重新开始。船体归零则熄火并进入最高 2.6 m/s 的应急划桨状态，仍用 WASD 驶向小岛，砍树修复后继续航行。码头附近是安全锚地，上岸时不受攻击。

目标是进入灯塔外侧 65 米抵达区，必须处于驾驶状态且船体已修复到大于 0。沿罗盘灯塔方向航行即可完成，潜水是可选探索。熟悉驾驶后直航约 2.5 分钟，加入潜水和靠岛修理通常 5–10 分钟，也可以无限停留。

## 实现

Three.js + TypeScript + Vite，原创程序化建模和着色。鲨鱼采用连续曲面体型、背腹配色、鳍、鳃、眼和口部细节、活动下颌与双排三角牙齿，身体与尾鳍持续摆动；15 条动物随航程逐渐加入，拥有巡游、绕行、观察、蓄势、冲击、退避和受伤状态。跃水事件使用连续弹道，经过船首上方，带入水 / 出水水花。

海面有连续波浪位移、微波纹、天空反射、泡沫和尾流；船体跟随同一波场起伏。水下是同一三维海域，具备水面顶层、深度雾、光束、悬浮物、鱼群、岩石、海床、海草和少量沉船。所有声音由 Web Audio 实时合成。

视觉风格追求写实，但使用原创程序化模型与实时近似渲染，并非照片级扫描资产。攻击和修理频率服务于游戏，不是野生大白鲨行为的科学模拟。

这是桌面键鼠 Demo。船和鲨鱼使用适合游戏的近似物理与碰撞体；海面采用实时近似反射，未使用完整流体求解。没有针对手机触控、VR 或所有显卡做兼容保证。

## 测试

`npm.cmd test` 运行规则、航行和鲨鱼行为测试。先启动开发服务器，再运行：

```powershell
npm.cmd run test:browser
# 先运行生产预览，再检查岛屿与破笼升级：
node tools/upgrade-test.mjs
```

浏览器测试使用本机 Chrome / Playwright，真实键盘鼠标操作覆盖驾驶、甲板行走、升降和攻击。`?qa=1` 才开放场景设置与时间加速钩子，用于复现跃水、战斗边界和结束流程；普通地址只有只读检查快照。详细证据和测试范围见 `VALIDATION.md` 与 `qa/browser-report.json`。

## 文件

- `src/main.ts`：输入、相机、HUD、场景与音效调度。
- `src/game.ts`：航行、交互、状态、战斗资源、胜负规则。
- `src/sharks.ts`：原创白鲨模型、游动、行为和碰撞。
- `src/ocean.ts`：水体、天空、海床、环境与水花。
- `src/vessel.ts`：船、潜笼、工具和装备模型。
- `src/islands.ts` / `src/shore.ts`：四座岛屿、码头、树木、砍伐与斧头。
- `src/damage.ts`：船体裂口、修补木板、应急船桨与笼架变形。
- `src/audio.ts`：海洋、引擎和水下音效。
- `ASSETS.md`：资源与许可证说明。
