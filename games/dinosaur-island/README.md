# 逃离恐龙岛 · V0.4

一个以 Three.js 为核心的桌面 Web 原型：控制带骨骼动画和真实纹理的霸王龙或迅猛龙，穿过海岸、蕨叶林、河流与山脊，追赶小兽并进食维持生命。
当前交付优先验证场景、角色和操作感；视觉质量仍受 V0 调整时间、免费模型及动画的上限约束，没有宣称达到电影或商业大作品质。

## 启动

需要 Node.js 22.17 或更新版本、支持 WebGL2 的桌面浏览器，以及键盘和鼠标。本机使用 Node.js 22.17.0。
已加入平板触屏方向、奔跑及动作按钮；真实平板性能仍需设备验证。电脑请使用开启硬件加速的 Chrome 或 Edge。

Windows 双击 `start.cmd`，服务准备好后会自动用默认浏览器打开 [本地体验](http://127.0.0.1:5182)。首次启动会安装缺少的 npm 依赖；重复双击会复用已运行的游戏服务。游玩期间请保留服务窗口，按 Ctrl+C 可停止服务。
也可以在本目录运行：

```powershell
npm.cmd ci
npm.cmd run dev
```

```powershell
npm.cmd test          # 控制器、音频和生存规则回归
npm.cmd run build    # 类型检查与生产构建，输出 dist/
npm.cmd run preview  # 在 http://127.0.0.1:4182 预览构建
```

端口被占用时请先结束本项目原有进程。浏览器必须通过本地 HTTP 服务打开；直接双击 `index.html` 无法加载模块和模型。
模型、贴图与天空随项目提供，运行时无需登录资源网站或连接外部 CDN；界面使用系统字体。

## 操作与本版内容

| 操作 | 功能 |
|---|---|
| W / A / S / D，或方向键 | 相机方向对应的移动 |
| 按住 Shift | 奔跑 |
| 鼠标左键或右键拖动 | 环顾角色 |
| 鼠标滚轮 | 调整跟随距离 |
| R，或点击“吼叫” | 昂首、大幅张嘴咆哮，附近小兽受惊逃跑 |
| Space，或点击“攻击 / 倒树” | 攻击前方猎物 / 霸王龙，或撞倒挡路的树 |
| E，或点击“进食” | 靠近倒下的猎物，停步进食 |
| Esc，或右上设置 | 暂停、切换恐龙、画质、声音、重新开始 |
| P，或相机按钮 | 隐藏 HUD；摄影界面可保存画面 |

已包含：有限岛屿地形、海面、海滩、扫描岩石和植物、棕榈、太阳阴影、雾、第三人称相机、基础动作、主要障碍与海水边界、小地图、合成环境音。

V0.3 的岛上共有 17 个居民（不含玩家）：1 只霸王龙、4 只迅猛龙、2 只梁龙、2 只犀牛、4 只狐狸、4 只乌鸦。迅猛龙、梁龙、犀牛和乌鸦使用各自独立的模型与骨架。
迅猛龙和狐狸可捕猎，会游荡、逃跑、绕开树干与河岸；大动物漫步并注意靠近的玩家；乌鸦沿空中路线振翅飞行。金色小地图点是可捕食目标。出生海岸右前方有迅猛龙，左前方林地有犀牛和梁龙。

霸王龙保留原始皮肤纹理和法线，修正旧材质转换的异常折射率，使用低饱和土色皮肤；胸部有呼吸起伏，身体随坡度缓慢俯仰，下水后皮肤渐湿，回到陆地会缓慢干燥。原来的昂首张嘴吼叫保留。

追上狐狸或迅猛龙，头部朝向它，按 Space 咬倒后再按 E：进食需 2.2 秒，恢复 42 饱食度和 15 生命，最高均为 100。咬击本身不恢复食物。远离玩家的猎物可在约 70 秒后刷新。
不进食时饱食度持续减少；静止/步行约 6 分 40 秒耗尽，持续奔跑更快。空腹后每秒失去 5 生命，最多再坚持约 20 秒，随后死亡并可重新开始。暂停和隐藏页面不会继续消耗食物。

沿岛东侧的蓝色河道可以下水、穿越，涉水降低速度；目前是浅河涉水，没有游泳、潜水或口渴系统。R 的 4 秒吼叫叠加头颈上抬和约 62° 下颌开合，结束后恢复正常姿态。
没有采集、建造、背包、造船、剧情、多人或复杂生存系统。梁龙和犀牛目前用于环境互动，不能捕食。

## V0.4 角色、倒树与战斗

- 在首页选择恐龙，或点击左下“切换恐龙”进入设置。当前两种可玩角色为霸王龙和迅猛龙，各用原有真实模型与动画；没有加入翼龙 / 棘龙，也不提供飞行。迅猛龙步行 / 奔跑为 4.4 / 12 m/s，霸王龙为 3.2 / 9.2 m/s；相机高度与碰撞体随体型调整。
- 切换保留位置、生命、饱食度与岛上状态；动作未结束、受到追击或目标体型会卡入障碍时不能切换。重新开始保留选中物种，恢复全部生存数值与岛屿居民。
- 面向挡路树干按 Space。全岛 172 棵棕榈和岛树共用倒树状态：树干与树叶一起倒下，立即解除移动 / 镜头 / NPC 碰撞，残木随后缩退。第 58–60 秒长回，60 秒恢复碰撞；站在树根处会延后恢复，离开后再长回。暂停和切出页面不计时，石头不可破坏。
- 野生霸王龙原本不主动攻击；被击中后追击，靠近时蓄力 0.75 秒再反咬，每次伤害 18，攻击间隔 2.8 秒。留意顶部血条与蓄力提示，侧移或拉远可躲避；离开追击范围后才能换角色。
- 野生霸王龙生命为 180，玩家霸王龙 / 迅猛龙每次伤害分别为 45 / 30。一般需要 4 / 6 次命中；树干和岩石会挡住双方咬击。战斗会损失生命并可能死亡，死亡提示与饥饿区分。
- 击败霸王龙后用 E 进食，每次 2.2 秒。尸体有 3 份，每份恢复 85 饱食度、30 生命（上限 100）；普通猎物为 1 份、42 饱食度、15 生命。不会因攻击自动进食，也没有无限食物。

运行 `node tools/v04-smoke.mjs` 验证角色切换、倒树穿行、真实 60 秒再生、霸王龙反击 / 战斗死亡 / 多份进食；需要 5182 开发服务。资产均复用已有免费素材，未新增外部下载。

## 技术路线为何这样收敛

运行栈为 **Three.js 0.180.0 + TypeScript + Vite**，使用稳定的 WebGL2 路径。
直接复用官方 [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)、[动画混合](https://threejs.org/manual/pages/animation-system.html)、[Water](https://threejs.org/docs/pages/Water.html)、RGBELoader（Sky 为备用）；环境使用 PBR 贴图、按空间分块实例化、透明裁切及有限范围阴影。
资源预处理使用 [glTF Transform](https://gltf-transform.dev/)；交付模型已经转换，无需用户安装 Blender 或重复下载资源才能运行。

| 候选 | 此次决定 |
|---|---|
| 原生 Three.js + Vite | 采用。单场景和少量角色，便于直接调整画面和控制；运行依赖只有 Three.js。 |
| [R3F + ecctrl](https://github.com/pmndrs/ecctrl) | 有成熟角色控制能力，但同时引入 React/Fiber/Rapier 及其版本配合；当前范围的收益不足以抵消集成成本。 |
| [Sketchbook](https://github.com/swift502/Sketchbook) | 可参考第三人称思路；上游已明确停止维护并归档，不作为新项目基础。 |
| [Rapier 角色控制器](https://rapier.rs/docs/user_guides/javascript/character_controller/) | 暂未引入。出现台阶、移动平台或更严格的实体碰撞需求时再采用；它本身也不负责旋转碰撞。 |

地形高度由渲染和移动共用；控制器只做高度跟随、圆形障碍代理和简单相机视线检测。
这种限定范围的适配避免自建通用游戏引擎，也明确不等同于完整刚体物理。
代码库的 MIT 许可与模型许可分别核验，不能因为示例开源就把其所有素材视为同一许可。

## 免费资源与真实限制

- 恐龙：[LasquetiSpice 的 Animated Tyrannosaurus Rex Dinosaur Running Loop](https://sketchfab.com/3d-models/animated-tyrannosaurus-rex-dinosaur-running-loop-38007d947ae74dea83988cb0b08ee053)，CC BY 4.0。实际模型与原始许可已随项目保留。
- 环境：[Poly Haven](https://polyhaven.com/) 的 Fern 02、Island Tree 02、Rock Moss Set 01、Anthurium Botany 01、Coast Sand 01、Forest Ground 04 和 Kloofendal 38d Partly Cloudy Pure Sky，CC0。
- 水面法线来自 [Three.js r180 示例纹理](https://github.com/mrdoob/three.js/blob/r180/examples/textures/waternormals.jpg)，随 Three.js MIT 许可记录。
- 小型猎物：[Khronos Fox](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox)，模型 PixelMannen（CC0），动画 tomkranis、转换 AsoboStudio / scurest（CC BY 4.0）。当前是风格化狐狸，与主角写实程度有差距。
- 新物种：Ferocious Industries 的迅猛龙、GremorySaiyan 的犀牛、Alexei Ostapenko 的乌鸦均为 CC BY 4.0；Skorpio 的梁龙使用 CC BY-SA 3.0，衍生模型和新增动画沿用该许可。详见 [新增物种来源](public/assets/animals/SOURCE.md)。
- 全部来源、作者及加工说明见 [总授权说明](THIRD_PARTY_NOTICES.md)、[恐龙来源](public/assets/dinosaur/SOURCE.md) 和 [环境说明](ASSET_ENVIRONMENT.md)。

恐龙确有 `idle`、`run`、`roar`、`bite`、`attack_tail` 动画；本版使用前四者，**步行复用降速的奔跑循环**，转向由角色控制器完成。进食和夸张咆哮叠加骨骼姿态，NPC 通过 SkeletonUtils 克隆骨架与独立动画混合器，共享资源。
没有独立步行动作、足部 IK 或全身碰撞，因此急转与坡面可能存在滑步、脚部悬空或头尾穿过植被等 V0 痕迹。
棕榈为程序生成的背景近似，海水为平面反射效果，环境音和吼声由 Web Audio 原创合成；不是扫描棕榈、流体模拟或录制的影视音效。
首要瓶颈是动画与模型质量、植被透明覆盖/阴影成本、场景构图，以及模型首次加载；增加玩法系统不会解决这些问题。

## 验证范围

截至 2026-09-28，`npm test` 的 **32/32** 项测试通过，覆盖移动、边界、障碍、暂停、吼叫、重置、相机、静音、涉水、捕食和饥饿死亡。
这些是基于真实 Three.js 数值与模拟 DOM/AudioContext 的回归，不能替代浏览器视觉验收。
浏览器实测记录和截图在 `qa/`。新增物种和霸王龙材质/呼吸/湿润效果的流程检查为 `node tools/wildlife-smoke.mjs`（需要 5182 开发服务）；独立资产检查页为 `/tools/inspect-animals.html?kind=raptor`，仅开发服务提供。运行 `node tools/browser-smoke.mjs` 重做漫游检查（需要本机 Chrome 与已启动服务；用 `ISLAND_URL` 指定其它地址）。`node tools/survival-smoke.mjs` 验证 12 项生存流程，需要 5182 开发服务；它通过仅开发环境存在的 `?qa=1` 场景入口布置猎物/河流/临死状态，实际操作使用键盘和按钮。生产构建不包含场景入口。性能与验证边界见 `QA.md`。

默认画质为自适应；连续帧率较低时降低内部渲染分辨率和阴影精度。可在暂停界面手动选择高画质或流畅。当前优化包括树冠叶卡 LOD、分块可见性、限制远处植被及水面反射物体、15 Hz 阴影刷新；不是完整开放世界 LOD 系统。

## 本版停止标准

能进入场景并完成海岸→森林→河流的漫游，看见其他恐龙，完成追赶→咬击→进食；长时间不吃会死亡，重新开始恢复场景；连续两次吼叫均能昂首张嘴。基础操作、暂停和资源加载无阻断错误后冻结这一切片。
新增物种完成到“能认出不同种类、会动、在岛上可遇见”就停止。下一步优先改善狐狸素材、足部贴地、梁龙步态和明确设备上的性能，本版仅增加角色切换、倒树再生与玩家对霸王龙战斗，不继续扩张世界或战斗系统。

## 代码入口

`src/main.ts` 负责界面和流程，`world.ts` / `terrain.ts` 负责环境与河流，`dinosaur.ts` 负责模型与骨骼姿态，`controller.ts` 负责移动和相机，`survival.ts` 负责生存/捕食/游荡，`wildlife.ts` / `animals.ts` 负责动物渲染，`species.ts` 记录物种规则，`player.ts` 负责两种可玩角色，`trees.ts` 管理倒树与再生，`audio.ts` 负责声音。
下载和加工脚本在 `tools/`；原始来源清单在 `public/assets/`。优先替换素材和调整场景参数，避免把 V0 拆成通用框架。

V0.3 没有替换霸王龙拓扑或重制完整步行/足部 IK；它是材质与动态表现的改进。梁龙源模型较简单，新增步态是程序制作的基础循环；不把这些改动描述为电影级写实。
