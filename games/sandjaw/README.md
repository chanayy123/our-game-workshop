# 伏沙猎手 · SANDJAW — 第三人称版

从鳄鱼背后跟随探索沙滩、水面和海底的三维生存游戏。默认使用第三人称镜头：完整鳄鱼可见，鼠标环顾、相对朝向移动与侧移。控制一只从 3.2 米成长到最多 50 米的湾鳄，捕食、潜沙伏击、躲避警察、探索海底并与鲨鱼交战。东侧的 9 米巨鳄会威胁幼鳄，长到 9 米后它会让开领地。

2026-10-02 更新：鳄鱼身体加宽加厚，生命上限 160，最多成长至 50 米；每次警察最多七人。水下耗氧降至 1.1 点/秒，海底沙藏耗氧 0.45 点/秒；鲨鱼蓄力 1.65 秒，单次伤害降低至 10，恢复期更长。新增海底潜沙、R 人形伪装、F 拖入水中、G 拖入沙里。继续采用第三人称，地面 4.6 米/秒，水中 6.2 米/秒，沙中 1.8 米/秒。


## 启动

需要 Node.js 22.17+、npm，以及支持 WebGL 的现代浏览器。建议使用桌面键盘和鼠标。

**Windows 直接双击本目录的 `start.cmd`**：首次缺少依赖时自动安装，启动后自动打开浏览器；重复双击会复用已运行的游戏服务。游玩时保留启动窗口，关闭窗口或按 Ctrl+C 可停止服务。也可以在本目录运行 `cmd.exe /c start.cmd`。

```powershell
cd E:\workspace\github\codex-runs\G06-baseline-001
npm.cmd install
npm.cmd run dev
```

打开 <http://127.0.0.1:5186/>。如果 npm 的全局缓存目录不可写，可用 `npm.cmd install --cache .npm-cache`，该目录已忽略。

生产版本：

```powershell
npm.cmd run build
npm.cmd run preview
```

打开 <http://127.0.0.1:4186/>。开发与预览都只监听本机。

## 操作

| 操作 | 按键 |
| --- | --- |
| 向视线前后移动 / 左右侧移 | W、S / A、D |
| 环顾视角 | 点击画面锁定鼠标后移动鼠标 |
| 备用环顾方式 | 按住右键拖动，或使用方向键 |
| 短时冲刺 | 按住 Shift |

| 潜入沙里 / 出沙 | E，可在浅色沙滩或海底使用 |
| 岸上人形伪装 / 解除 | R，攻击、入水或潜沙时自动解除 |
| 抓住行人拖入水中 | F，靠近到 3.8 米内并朝向目标 |
| 抓住行人拖入沙里 | G，需要站在浅色沙滩 |
| 下潜 / 上浮 | Q，离开浅水区后使用 |
| 视野、灵敏度、舒适视角 | H 打开说明面板调整 |
| 释放鼠标并暂停 / 继续 | Esc / 面板中的继续按钮 |
| 查看操作说明 | H / 右上角问号 |
| 切换声音 | M / 右上角音符 |

进入游戏或点击继续时申请鼠标锁定，Esc 释放并暂停。浏览器不允许锁定时仍能用 WASD、方向键和右键拖动。窗口隐藏时自动暂停。触屏使用方向按钮移动、画面拖动环顾和底部动作按钮；主要验收对象是桌面键鼠。

视野可在 65–100° 调整；舒适视角关闭冲刺时的视野变化。系统偏好减少动态效果时默认开启。

## 游戏循环

- **捕食成长**：行人、鱼群、贝类和击退鲨鱼都能带来成长；上限为 50 米。水中食物可恢复生命和饱食，普通食物 35 秒后刷新。
- **沙地伏击**：潜沙后可以用 WASD 缓慢移动，保持隐蔽但不能冲刺；镜头仍从背后跟随，沙丘与沙纹显示藏身位置。移动限制在浅色沙滩，离开前需按 E 出沙。左键或空格捕获范围内的行人，将目标拖入沙里。伏击后仍保持隐藏，但目击者可以报警。
- **报警追捕**：附近部分目击者会停下打电话，橙色标记与倒计时提示报警。4.5 秒内捕获报警者能中断电话。报警成功 14 秒后警察到场，依报警次数为 3、5、7 人，之后每次保持七人。连续捕食不会延长已开始的电话。
- **警力门槛**：五名以内可逐个咬退；幼鳄面对六至七人的盾牌防线时咬击无效，成长到 12 米可突破。持续潜沙或潜水 13 秒可结束搜索；出沙或上浮会重新计算连续隐藏时间。
- **伪装与拖拽**：岸上按 R 变成人形，行人不会因靠近而逃跑；攻击时解除伪装，目击者仍可报警。F 自动把近身行人拖向水中，G 把行人拖进沙子；动作有移动与完成过程，完成后才计分。也可直接左键或空格吞食。
- **海底沙藏**：下潜后按 E 藏入沙床，鲨鱼会失去目标，仍可缓慢移动与拾取贝类、遗物；E 出沙，Q 直接上浮。沙藏仍消耗少量氧气，耗尽时自动上浮。
- **水面与海底**：鱼群在水面，贝类与三枚潮汐遗物在海底。下潜消耗氧气，上浮恢复；耗尽时会受伤并紧急上浮。浅水自动浮起。
- **鲨鱼战斗**：鲨鱼先蓄力，红圈及屏幕上的前方 / 左右 / 身后警告提示来袭方向，随后沿锁定方向冲撞，最后进入恢复期。侧移冲刺闪避，转头咬击；长到 9 米后每次造成 2 点伤害，25 米后可一口击退鲨鱼。正常咬击需要朝向目标。
- **完成试炼**：成长到 12 米、收集 3 枚遗物、击退 2 条鲨鱼，再回到地图西侧的静水巢穴。巢穴可以缓慢回血。胜利后可继续自由探索并成长至 50 米，也可重新开始；生命归零有明确失败原因与重开按钮。

小地图标出自己、行人、警察、遗物、鲨鱼、巢穴及巨鳄领地。主界面显示罗盘、巢穴距离、近身目标、生命、体力、氧气、饱食、成长、警戒和任务进度。

## 验证

```powershell
npm.cmd test
npm.cmd run build
# 先在另一终端启动 dev 或 preview
npm.cmd run test:browser
npm.cmd run test:playthrough
```

默认浏览器测试使用已安装的 Chrome 和 5186 端口。检查生产预览可设置 `$env:G06_URL='http://127.0.0.1:4186/'`。

`tests/game.test.ts`、`tests/giant.test.ts` 与 `tests/first-person.test.ts` 覆盖玩法、相对视线移动、咬击方向、俯仰限制、地形和碰撞。`tools/giant-test.mjs` 使用实际鼠标锁定、鼠标移动、右键拖动、按键和按钮，配合明确标注的场景设置测试危险情形。`tools/giant-playthrough.mjs` 只访问普通游戏 URL，通过只读状态选择实际移动、转头和咬击按键，完成不修改状态、不加速时间的一整局。

最终结果与范围见 [VALIDATION.md](VALIDATION.md)。当前巨鳄版本的报告和截图在 `qa/giant/`，`qa/third-person/`、`qa/first-person/` 和 `qa/` 顶层是历史证据。

## 实现与素材

- `src/game.ts`：独立规则、NPC、警察、鲨鱼 AI 和目标状态。
- `src/models.ts`：原创程序化鳄鱼、人物、鲨鱼、树木模型。
- `src/world.ts`：第三人称跟随镜头、完整鳄鱼与沙丘、场景、动画与特效。
- `src/environment.ts`：连续地形、程序化纹理、水面、天空、地标与海底细节。
- `src/first-person.ts`：相对视线移动、环顾角度、罗盘计算。
- `src/main.ts` / `src/style.css`：中文界面、输入、地图和状态提示。
- `src/audio.ts`：Web Audio 合成潮声与动作提示音，潜水与潜沙时低通处理。

模型、图标、界面、着色器和音效均在项目内生成，不使用外部图片、模型、字体或音频下载。风格为低多边形、非血腥表现。依赖 Three.js、Vite、TypeScript 和 Playwright；具体版本由 `package-lock.json` 锁定。

这是单人本地玩法原型，无联网、存档或照片级素材。树干、长椅和海底岩石使用简化碰撞，其他装饰没有完整刚体模拟。普通 URL 只提供只读诊断快照；可修改状态的测试工具仅在显式 `?qa=1` 页面出现。
