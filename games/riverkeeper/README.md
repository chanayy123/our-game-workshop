# 溪流手记 · Riverkeeper

一款可以实际改造河道的 3D 溪流小游戏。用石头和泥土筑坝、填缝、挖开支流，让两处干涸的小池重新蓄水；避开水蛇，完成挑战后继续自由实验。

## 运行

需要 Node.js 22.6+，推荐 Node.js 22 LTS，以及支持 WebGL 的现代桌面浏览器。

```powershell
cd E:\workspace\github\codex-runs\G03-baseline-001
npm install
npm run dev
```

打开 <http://127.0.0.1:5183/>。也可以双击 `start.cmd`，首次启动自动安装依赖。

```powershell
npm test
npm run build
npm run preview
```

生产预览为 <http://127.0.0.1:4183/>。启动开发服务后，`npm run test:browser` 使用本机 Chrome 执行浏览器回归，输出到 `qa/`。可用 `CREEK_URL` 环境变量指定另一服务地址。

## 玩法

- **WASD / 方向键**：沿画面方向移动，水中行走更慢。
- **1 石头**：放置大石块，连续摆放形成水坝。
- **2 泥土**：垫高地面、填补坝体空隙、围出岸线。
- **3 挖掘**：降低地面，长按连续挖掘，开出新河道。
- **4 移除 / 鼠标右键**：恢复局部原始地形，拆坝放水。
- **鼠标左键**：在玩家 5.5 米范围内施工。悬浮预览显示施工范围与有效性。
- **滚轮**：调整视野；**Esc**：暂停；**R**：重开确认；右上角可查看指南或开关声音。
- 窄屏提供方向按钮和触屏施工；主要面向桌面键鼠。

目标是让苔藓池、芦苇池的平均水深都达到阈值，并连续保持 12 秒。没有时间限制与材料上限。完成后可继续自由改造或重开。

水蛇在浅水中巡游，玩家在附近水域停留约 3 秒后会警觉，给出约 2 秒预警再追近。被咬后无法施工，必须走到干地开始 **10 秒** 恢复；期间重新入水会重置恢复计时。恢复后有 12 秒保护时间。蛇不会攻击岸上的玩家。

<details>
<summary>需要一点提示？</summary>

在 Y 形分岔下方横向放两块石头，抬高上游水位，再用挖掘工具挖开两侧浅褐色泥口。等待水顺着支流进入小池。也可以尝试只筑坝、只挖渠，或自己设计另一条水路；不同办法的蓄水速度不同。

## 实现

- **Three.js + TypeScript + Vite**，全部地形、植被、人物、水蛇与音效程序生成，无外部素材与在线资源依赖。
- `src/water.ts`：41 × 49 网格，高程与水深驱动的保体积通量模型。每条网格边按水面高差与地形阻挡传水；筑坝、填土、挖掘都进入同一个求解器。持续泉源和开放出口形成溪流。水流以 2 倍水力时间推进，增强变化可见性；这不是工程用途的物理求解器。
- `src/rules.ts`：移动、蛇的警觉与追逐、咬伤、上岸恢复、目标保持、暂停与完成状态。
- `src/world.ts`：3D 地形、动态水面与流纹、角色、蛇、植被、施工预览与粒子。
- `src/main.ts`：实际输入、UI、状态反馈和视图协调。
- `src/sound.ts`：Web Audio 溪流环境声、鸟鸣和操作提示音。

池塘统计使用实际模拟水深，不使用动画假填充。蓄水之后即使切断来水，池中仍可能保留积水；目标是让湿地蓄水，不是测量连续流量。

`?qa=1` 显式启用自动化测试接口；普通游戏地址不暴露该接口。浏览器测试使用真实键鼠施工、自然蛇警觉/追逐/咬伤及真实时间恢复；通过测试接口设置遭遇起点并加速水流等待，不把这些辅助步骤算作人工通关证据。
